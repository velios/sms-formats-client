# Handoff: повторный разбор PR 1003 (АТБ-ru) по новым правилам

Ты — исполнитель живого теста **точечного режима** работы с форматами. На банке АТБ-ru уже прогонялся комплексный режим («Привести банк в порядок», 2026-08-03: 2 слияния, 3 `<delete>`, чистая валидация). Теперь проверяем второй глобальный сценарий: **инкорпорировать один формат из PR в банк минимальными правками**, не задевая остальные форматы. Полигон — открытый апстрим-PR [zenmoney/sms-formats#1003](https://github.com/zenmoney/sms-formats/pull/1003).

## Что изменилось со времени прошлого прогона

Коммиты `9eddfc5` (пресеты + легенда) и `37cc89b` (правила дефолтов). Новые правила, действие которых этот тест должен показать:

1. **Дефолт у сущности ровно один** (cookbook §3, каталог сниппетов): альтернатива — только по триггеру, наблюдаемому в EXAMPLE, с причиной в отчёте. `([A-Z]{3})` и прочие сужения — не дефолт.
2. **`\s+` по умолчанию** (cookbook §4): `\s*` — только когда EXAMPLE показывают вариант и с пробелом, и без.
3. **Опциональные конструкции `(?:…)?` — только под наблюдаемую вариацию** (cookbook §4, антипаттерн 14).
4. **Консолидация через пере-выделение сущностей** (cookbook §5): разнице COLUMNS не верить на слово — сущности пере-выделяются из EXAMPLE, совпавшие наборы объединяются.
5. **Объём работ** (легенда): по умолчанию меняются только файлы, которых задача касается прямо; намерение пользователя выражается выбором пресета — «Починить изменённые файлы» (точечный) против «Привести банк в порядок» (комплексный).

## Фактура PR 1003

Бот `zenmoney-ai` добавляет один файл `src/АТБ-ru_4679/formats/Перевод Юлия Дмитриевна В Списано р СБП.txt`:

```
Перевод\s+(.+?)\s+Списано\s+(\d[\d\s.,]*)\s+([^\s║]+)(?:\s+║\s+.+)?

-----COLUMNS-----
payee;outcome;instrument

-----EXAMPLE-----
Перевод Юлия Дмитриевна В. Списано 500 р. ║ СБП
```

Что с ним не так по нашим правилам (это ожидания, а не подсказки агенту — в пакет их не вписывать):

- **Опциональная группа `(?:\s+║\s+.+)?` без наблюдаемой вариации** — пример один, и хвост в нём есть всегда. Плюс якорение переменного хвоста: поиск подстрочный, хвост можно просто не описывать.
- **Недефолтная валюта `([^\s║]+)`** — без причины, которую дают EXAMPLE.
- **Пересечение с существующим форматом `СБП Перевод Ольга Валентиновна К Списано р_11408.txt`**:

  ```
  СБП:\s+Перевод\s+(.+?)\s+Списано\s+(\d[\d\s.,]*)\s+(\S+)

  -----COLUMNS-----
  payee;outcome;instrument

  -----EXAMPLE-----
  СБП: Перевод Ольга Валентиновна К. Списано 10000 р.
  ```

  Regex PR-файла ловит пример 11408 (подстрока с «Перевод …»), — блок `intersections` пакета обязан это показать. COLUMNS совпадают, шаблон один (исходящий СБП-перевод), отличия только в префиксе/хвосте → по правилам это кандидат на объединение, а не на разведение lookahead'ом.
- Соседний `Перевод СБП от Иван Владимирович Р зачислено RUR С_5412.txt` — приход (`payee;income;instrument`, якорь «Зачислено»), его задевать не нужно.

**Ожидаемый исход:** пример PR-файла переносится в 11408 (якорь `СБП:` там придётся ослабить по реальным текстам двух EXAMPLE), PR-файл уходит блоком `<delete>` с причиной; либо агент прозой обосновывает, почему объединять нельзя. Остальные ~30 форматов банка не переписаны — это главный критерий точечного режима.

## Методика

1. Клиент (dev-сервер или sms.zentable.ru) → банк АТБ-ru → PR #1003 → «AI промпт».
2. Пресет **«Починить изменённые файлы»** (fixChanged) — текст не редактировать, это и есть проверка дефолтной формулировки точечного режима.
3. Пакет — внешнему агенту; ответ — через экран «Импорт ответа».
4. Независимая проверка (Python `re`, как у апстрима):
   `/Users/flocktory/Documents/Codex/2026-08-03/files-mentioned-by-the-user-legend/outputs/validate_answer.py` — применяет ответ поверх слоёв пакета, гоняет example_no_match / cross_match по всем парам / число групп.
5. Артефакты прогона (пакет, ответ агента, вывод валидатора) сложи в `.scratch/atb-pr1003/`.

## Критерии оценки

- Валидация чистая: каждый EXAMPLE матчится своим regex, ни одной пары cross_match, число групп = числу колонок.
- **Ни один EXAMPLE не пропал** — пример удаляемого файла обязан выжить в консолидирующем.
- **Минимальность:** тронуты только PR-файл и — обоснованно, прозой — 11408. Диффов по остальным форматам банка нет.
- Правки следуют дефолтам: `(\S+)` для валюты, `\s+` в склейке, без опциональных групп; каждая оставленная альтернатива объяснена в прозе.
- Проза перед блоками: что сделано и чего агент делать не стал и почему.

## Опционально: сравнительный прогон

Тот же пакет с пресетом «Привести банк в порядок» (tidyBank) — проверить, что комплексный режим с новым шагом «пере-выдели сущности при разных COLUMNS» не ломает достигнутое в прошлый раз (эталон: `agent_answer.txt` в папке артефактов 2026-08-03) и находит те же или лучшие слияния. Не смешивать с основным прогоном: это другой режим и другой отчёт.
