# 04 — Визуальные токены: палитры групп/частей, Recognition Progress, радиусы и шапки

**Тип:** AFK · **Blocked by:** нет — можно начинать сразу (точечные расхождения в зонах 01–03 финально добивает приёмка оркестратора)

## Что построить

Базовая палитра в `src/styles.css` **уже совпадает** с макетом один в один (макет строился из приложения) — её не трогать. Слайс закрывает прикладные палитры и геометрию:

1. **Палитра групп захвата** — пять циклических пар fill/border из макета (`groupPalette`): `#c4e8ac/#9fcba1`, `#f6d7a6/#e0bf8b`, `#c8c8ff/#acadfc`, `#f2cfff/#e1abf5`, `#ffc5bf/#ef9b95`; полный матч вне групп — голубой `#d5ebff/#9fcfff`. Применяется согласованно: поле regex (режим «Группы»), тестовая строка, точки и строки таблицы групп.
2. **Тона режима «Части»** — раскраска токенов по типам из `toneStyle`/`blockTone` макета (anchor/group/quantifier/alternation/escape/charclass/meta/literal) — в поле regex и в карточках «Части паттерна» вкладки «Пояснение».
3. **Recognition Progress — перевывод цветов из новой палитры.** В макете его нет (упрощённый движок прототипа) — это осознанный пробел макета, а не отмена фичи. Семантика ADR-0007 не меняется: распознанный префикс — те же fill/border групп (ярко), нераспознанный хвост — нейтрально, dashed-обводка/волнистый хвост/пульсирующая каретка — в акценте `#3464a3`/нейтральных тонах новой палитры.
4. **Геометрия**: аудит по компонентам — панели 8px, контролы 6px, модалки 10px, инпуты 4–6px; шапки панелей 40px, капс 12px, letter-spacing 0.5px, фон `--c-bg-elevated`; ghost-кнопки шапок 26px. Хардкоды цветов мимо `--c-*`-переменных, найденные по пути, переводить на переменные.
5. **Не трогать**: шрифты (Geist/JetBrains Mono уже локально через fontsource; Google Fonts из макета не тянуть), спящие dark-переменные, `min-width:1200px`.

## Критерии приёмки

- [ ] Группы 1–5 и далее по циклу раскрашены парами из макета синхронно в поле regex, тестовой строке и таблице групп; полный матч — голубым.
- [ ] Режим «Части» и вкладка «Пояснение» используют тоновые пары макета по типам токенов.
- [ ] Recognition Progress различим во всех состояниях (полный матч / частичный префикс / нераспознанный хвост) в новых цветах; тесты ADR-0007 зелёные.
- [ ] Радиусы и шапки панелей единообразны по всем экранам и модалкам (8/6/10px, шапки 40px капсом).
- [ ] Никаких новых хардкодов цветов — только `--c-*`-переменные.
