Порядок работы над форматом

Сначала зафиксируйте литералы шаблона (всё, что не меняется от SMS к SMS), затем замените переменные куски группами захвата из библиотеки сниппетов. Каждая группа захвата сопоставляется со столбцом — порядок групп строго следует порядку токенов в SMS.

Суммы и балансы

Дефолт для суммы — (\d[\d\s.,]*). Знак минуса выносится из группы захвата, иначе значение не совпадёт с value. Для баланса почти всегда нужны обязательные копейки: (-?\d[\d\s.,]*[.,]\d{2}), иначе в группу утечёт время.

Пересечения форматов

Regex одного формата не должен совпадать с примерами другого. Кнопка «Посчитать пересечения» проверяет каждый regex против всех примеров банка; красный счётчик в списке файлов открывает scoped-вкладку «Пересечения».
