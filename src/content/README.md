# Контент-источники редактора regex

Три независимых, человекоредактируемых источника, которые собираются на сборке
(`scripts/build-content.ts`, см. ADR-0009). Сгенерированные артефакты
(`*.generated.ts`) лежат рядом, в `.gitignore`, и пересоздаются хуками
`predev`/`prebuild`/`pretest`/`pretypecheck`.

Каждый источник даёт и производный вид, и **сырой исходник** — последний нужен пакету
промта (ADR-0016): `COOKBOOK_HTML` + `COOKBOOK_MARKDOWN`, `FORMAT_RULES_HTML` +
`FORMAT_RULES_MARKDOWN`, `REGEX_SNIPPETS` + `SNIPPETS_TOML`.

## `cookbook.md`

Вендоренный **снапшот** `docs/transaction_sms_regex_cookbook.md` из репозитория
`zenmoney/sms-formats`. Синхронизируется **вручную**: при правках первоисточника
скопируйте файл заново. В приложении это снимок, не «живая» версия — рядом с
модалкой есть ссылка «открыть на GitHub».

## `format-rules.md`

**Наш** документ: контракт файлов апстрима `zenmoney/sms-formats` плюс раздел «где
наше приложение мягче». Отрисовывается в приложении рядом с cookbook (кнопка
«Правила формата» в шапке лаборатории regex). При обновлении апстрима сверяется
вручную, как и вендоренный cookbook.

## `regex-snippets.toml`

Каталог вставляемых сниппетов regex по сущностям. Редактируется без захода в код.
Каждый сниппет — таблица `[[snippet]]` с полями `group`, `pattern`, `desc`,
`trigger`, `example`, `gotcha`, `kind` (`default` | `alt`). `pattern` — литеральная
строка TOML (`'...'`), regex дословно, без экранирования бэкслэшей. Легаси-паттерны
(«не копировать») карточками не показываем. Проза — на русском.

Каталог наполнен единоразово из раздела 3 cookbook (bootstrap) и дальше живёт сам —
с cookbook он не синхронизируется автоматически и может расходиться.
