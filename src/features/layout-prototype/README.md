# Прототип изменения ширины панелей

Изменение ширины боковых колонок включается отдельной кнопкой. Пользователь проверил прототип и утвердил поведение без изменений.

Из корня репозитория:

```sh
git switch codex/prototype-resizable-panels
bun run dev
```

Откройте адрес, напечатанный Vite, и PR. Для примера со скриншота используйте путь `/repo/zenmoney/sms-formats/pr/1126/`.

1. Нажмите кнопку с тремя колонками рядом с настройками токена.
2. Потяните синюю границу слева или справа от редактора.
3. Сожмите колонку до края, она свернётся в полоску. Двойной щелчок по границе тоже сворачивает колонку.
4. Нажмите стрелку на полоске, чтобы восстановить ширину.
5. Повторное нажатие кнопки в шапке выключает перетаскивание и оставляет выбранные размеры.

С клавиатуры: Tab выбирает границу, стрелки меняют ширину, Home сворачивает, Enter переключает сворачивание. Стрелка разворачивания доступна и после выключения настройки.

Размеры и режим не сохраняются после перезагрузки. Левая колонка меняется целиком, вместе с действиями и файлами. Центральная занимает оставшееся пространство.

В этой копии репозитория отсутствуют `design/app.pen` и `design/notes/agent-design-guide.md`; макет Pencil не обновлён. Прототип использует существующие компоненты приложения и реальные данные открытого PR.

Проверены сборка, TypeScript, тесты AppHeader и RegexLab, перетаскивание обеих границ и восстановление в Chrome.
