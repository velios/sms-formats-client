# Предкомпиляция распознавания и кэш по содержимому

Бот многократно распознаёт SMS по одному корпусу. Перекомпиляция всех выражений на каждый вызов расточительна, а собственный механизм бота нарушил бы единство распознавания.

Ядро предоставляет API `compileRegexes` и `recognizeWithCompiled`: первый компилирует выражения общим компилятором с флагом `d` и резервным режимом, второй один раз нормализует SMS и возвращает результаты в порядке входных выражений. Пустое выражение не считается ошибкой, невалидное возвращает ошибку. `regexesBySms` объединяет эти операции, сохраняя единый путь распознавания.

Бот компилирует корпус при обновлении снимка и переиспользует результат до следующего обновления по TTL. Кэш принадлежит вызывающей стороне и привязан к содержимому или явной версии, например SHA вершины PR; путь или идентификатор формата недостаточен, поскольку выражение под ним меняется. Ядро остаётся чистым и не хранит кэш. Фронтенд компилирует живые строки при каждом вводе.

Перекомпиляция корпуса на каждый SMS отвергнута как лишняя работа. Собственная компиляция и проверка в боте отвергнуты из-за дублирования семантики распознавания.
