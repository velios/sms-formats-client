# Пересечения банка: глубокий модуль `useIntersections` — сигнальный контракт с вкладкой, сброс по идентичности внутри

## Контекст

Семантика инструмента пересечений задана ADR-0011 (направленная метрика, замороженный набор, живые бейджи). Этот ADR — про форму кода: сегодня у инструмента нет модуля. Состояние (снапшот `intersectionFormatEntries`, `hasCalculatedIntersections`, счётчик и текст ошибок, `isCalculating`, `intersectionRunIdRef`, `intersectionScope`), производные (`visibleIntersectionEntries`, `formatIntersectionStats`, `intersectionScopeFiles`), три хендлера и два эффекта сброса рассыпаны по `BankWorkspace.tsx` (~3500 строк) — интерфейс кластера равен его реализации, гонки и заморозка тестируются только рендером всей страницы.

Размазанность уже дала баг: эффект сброса при смене банка/источника обнуляет снапшот и флаги, но **не** `intersectionScope` и не `formatTab`. `BankWorkspace` не ремоунтится при смене параметров маршрута, поэтому после перехода в другой банк scope фильтруется по чужим файлам в пустой **массив** (truthy) — вкладка «Пересечения» остаётся видимой с нулём, а если пользователь стоял на ней, он видит пустой список.

## Решение

Выделить фичу `src/features/intersections/`: хук `useIntersections` плюс чистая сердцевина (решение «принять/отбросить результат по runId», слияние live-правки в снапшот, фильтрация scope по живым файлам — отдельные чистые функции). Полноценный reducer не вводится: машинная церемония для пяти состояний не окупается; апгрейд механический, если машина обрастёт.

Контракт шва:

- **Модуль владеет** снапшотом, статистикой бейджей и scope. **Вкладка остаётся у вызывающего**: операции scope возвращают сигнал «набор поднят/сброшен», и `BankWorkspace` одной видимой строкой мапит его на `formatTab`. Инвариант ADR-0011 «клик по числу = набор + таб» собирается на шве, а не прячется в эффекте-наблюдателе.
- **Сброс — инвариант модуля.** Хук принимает идентичность `{bankPath, repository, sourceRefName}` и при её смене сбрасывает всё, включая scope, — забыть невозможно. Это исправляет описанный баг (фикс входит в объём рефакторинга и получает тест). Нынешняя семантика отмены сохраняется byte-for-byte: правка драфта или смена списка файлов мид-флайт тихо гасит расчёт без сообщения — поведение спорное, но это кандидат на отдельное решение, не на дрейф внутри рефакторинга.
- **Ошибки — кодами** (`no-source | missing-pr-number | load-failed`) плюс `loadErrorsCount`; переводит рендер. i18n из логики уходит.
- **Загрузчик инъецируется**: параметр `loadEntries?: typeof prepareFormatEntries` с продакшен-дефолтом. `prepareFormatEntries` остаётся в `quick-check` как общий загрузчик; связь между фичами видна в шве, а не в импортах. Прод-адаптер + тест-фейк = два адаптера, шов настоящий: отмена гонки тестируется контролируемым промисом без рендера страницы.
- **`window.confirm` перед пересчётом — у вызывающего**; модуль экспонирует `hasCalculated`. Подтверждение — UX-политика страницы, не инвариант пересечений.
- **Имя — `useIntersections`** (инструмент целиком: снапшот + бейджи + scope), не `useIntersectionsScope`: scope — лишь часть содержимого, имя по части дезориентирует. Статья в CONTEXT.md уточняется при имплементации (снапшот сейчас упомянут только косвенно).

## Альтернативы

- **Модуль владеет и `formatTab`.** Закрывает баг конструктивно, но затягивает в модуль вкладки «Все»/«Недавние», к которым он отношения не имеет, — шов поперёк чужого концепта.
- **Таб у вызывающего без сигнала** (наблюдение за scope эффектом). Инвариант «набор + таб» разрезан на два места невидимым образом — ровно так уже потеряли сброс.
- **`reset()`/`cancel()` дёргает вызывающий.** Воспроизводит архитектуру бага: сброс снова живёт у забывчивого вызывающего.
- **Инъекция `confirmRecalculate`.** Колбэк-дырка в интерфейсе ради одного UI-жеста.
- **Переведённые строки ошибок (передавать `t`).** Чужая зависимость в шве навсегда; тесты сравнивали бы русские строки.
- **Прямой импорт загрузчика + vitest-мок.** Тестовый шов неявный, завязан на путь файла.
- **Чистая машина (reducer + команды) + хук-адаптер.** Глубина ради глубины при ~150 строках логики.

## Последствия

- `BankWorkspace` теряет ~400 строк и семь кусков состояния; гонки, заморозка и слияние live-правок тестируются через интерфейс хука и чистые функции.
- Существующие `BankWorkspace.intersections.behavior.test.tsx` переживают рефакторинг без правок поведения и остаются регрессионной сеткой поверх нового шва.
- Единственный поведенческий дифф — баг-фикс: смена банка/источника обнуляет scope, сигнал уводит вкладку с «Пересечений»; на это пишется тест.
- Тихая отмена расчёта при правке мид-флайт задокументирована здесь как сохранённая осознанно; её пересмотр (сообщение пользователю? авто-перезапуск?) — отдельное будущее решение.
- CONTEXT.md не правится до имплементации; при имплементации — уточнить статью «Intersections scope» (или добавить объемлющий термин для инструмента).
