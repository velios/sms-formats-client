# Пакет промта: чистая сборка и отдельное получение данных

Пользователь задаёт задачу и выбирает справочные документы для текстового пакета одного банка, который передаёт внешнему агенту. Приложение собирает пакет, но не исполняет его. Материалы приходят из черновиков, удалённых ревизий и сборки контента; пофайловый REST для крупного банка требовал бы сотен запросов при анонимном лимите 60 в час.

`buildPromptPackage` — чистая функция от названия банка, файлов трёх слоёв, выбранных документов и задачи. Она возвращает текст и сводку: число файлов каждого слоя, включая нулевое, документы, размер в байтах, оценку токенов и пропущенные файлы. Порядок блоков — легенда, документы, пересечения, три слоя файлов и задача; пустой слой не печатается. Сеть, сторы и сохранённые настройки находятся в `usePromptPackage`, интерфейс — в модальном окне.

Пути слоёв предоставляет инвентарь банка, а не повторная арифметика в сборщике. В пакет входят формат-файлы и `senders.txt`, без неподдерживаемых файлов, которые upstream удаляет. Базовый слой `main` — исторический общий коммит веток PR и main, слой `pr` — head сессии; правила явных удалений и единый кэш по репозиторию, SHA и пути заданы [ADR-0018](0018-coherent-revisions-and-publishing.md).

Удалённые тела получает хук через GraphQL с алиасами, порциями примерно по 50. Пользовательский токен обязателен; анонимный режим не подходит. Слои запрашиваются из базового репозитория, включая head внешнего PR, даже закрытого без слияния. Порции ограничивают риск таймаута и недокументированного потолка алиасов. Отсутствующий объект означает отсутствие файла; бинарное или обрезанное тело исключается из текста и явно попадает в список пропусков, чтобы не выдать неполную загрузку за отсутствие файла.

Контент-пайплайн включает сырые Markdown cookbook и правил форматов, а также исходный TOML сниппетов рядом с HTML и типизированным каталогом. Это увеличивает бандл, но сохраняет исходную структуру без второго сериализатора. Документ правил описывает контракт upstream и ограничения приложения и вручную сверяется при обновлениях. Сборка пакета объясняет ограничения агенту, не меняя поведения редактора.

Легенда и шаблон пакета русские и не зависят от языка интерфейса. Задача и выбор документов сохраняются в одном объекте localStorage на всё приложение: формулировку можно повторять для разных банков. Очистка удаляет этот объект. Сборка доступна и в режиме чтения при наличии токена.

Загрузка внутри чистого сборщика отвергнута как смешение сериализации и сетевого состояния. Кэш по номеру PR отвергнут, поскольку смешивает разные ревизии. Использование расчёта пересечений для получения тел отвергнуто из-за отсутствия базового слоя, отправителей и исходного текста. Пофайловый REST отвергнут из-за объёма запросов; `git/trees` и `git/blobs` — из-за отсутствия пакетной загрузки. Один большой GraphQL-запрос отвергнут, поскольку таймаут терял бы весь пакет. Сериализация каталога сниппетов в новый текстовый вид отвергнута из-за расхождения с TOML, HTML документов — из-за лишней разметки. Легенда в i18n отвергнута как зависимость языка артефакта от интерфейса. Настройки на каждый банк отвергнуты, поскольку мешают повторному использованию задачи.
