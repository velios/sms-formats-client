# В чужом чате распознавание требует `/sms`

Упоминание бота ради рекомендации не должно вызывать распознавание и ненужный ответ в чужом чате. Намерение распознать обозначается командой `/sms`; в личной переписке команда необязательна.

После удаления упоминания в guest-вызове отсутствие ведущей `/sms` означает тишину, даже при reply. Вебхук подтверждается HTTP 200 без отправки guest-ответа: намеренное молчание не блокирует очередь, в отличие от ошибки отправки. При `/sms` без аргумента распознаётся текст reply, а при выделенной цитате — только её текст. Без reply распознаётся аргумент команды. Одновременные reply и непустой аргумент дают подсказку о конфликте; отсутствие обоих — подсказку о способе вызова.

Рабочая форма в чужом чате — настоящее `@zenmoneysms_bot`-упоминание и отдельная `/sms`. Форма `/sms@zenmoneysms_bot` не поддерживается: Telegram считает её командой без упоминания и не доставляет такой guest-вызов.

В личке текст без команды передаётся распознаванию целиком, без предварительного изменения. Ведущие `/sms` и `/sms@zenmoneysms_bot` удаляются; пустая `/sms`, `/start`, `/help` и нетекстовые сообщения дают личную подсказку. В обоих режимах команда распознаётся без учёта регистра после обрезки краёв, заканчивается пробелом или концом строки и удаляется до нормализации. `/smskaspi` командой не считается.

Разные извлекатели возвращают SMS, готовую подсказку или, только для guest, молчание. Общая функция формирует ответ; без готового корпуса на SMS отвечает сообщением об инициализации. Общий обработчик ведёт пробный режим и подавляет ошибки отправки, а способы доставки guest/direct остаются отдельными адаптерами. Личная, гостевая и конфликтная подсказки различаются.

Описание профиля объясняет вызов до начала переписки; подсказки появляются по запросу. Нативное меню `/sms` используется только в личке: наличие меню для guest-бота документацией не подтверждено, а вставляемая им форма всё равно не вызывает бота. Настройка профиля отделена от регистрации вебхука.

Ответ со списком команд на любое упоминание отвергнут, поскольку сохраняет шум. Reply без команды отвергнут ради единого признака намерения. Подсказка на любой ведущий слэш в guest отвергнута как новый источник шума. Выбор одного из двух источников SMS отвергнут из-за риска угадать неверно. Тег подсказки без текста отвергнут, поскольку потребовал бы различать режимы в общей функции ответа. Две функции ответа отвергнуты из-за дублирования обработки одинаковых исходов.
