# Выделение группы: чистый автомат и тонкий хук

Для выделения из [ADR-0010](0010-capture-group-selection-for-snippet-replacement.md) нужно отличать замену сниппетом от обычной смены regex. Реф-флаг и разрозненные эффекты привязывают сохранение выделения к порядку обновлений и затрудняют проверку без CodeMirror.

Состоянием управляет чистый редьюсер, поверх которого работает `useGroupSelection`. В отличие от [пересечений](0013-intersections-deep-module.md), здесь автомат оправдан переплетёнными правилами сброса: одноразовый признак замены становится данными, а сохранение выделения — проверяемым переходом.

Состояние — выбранный номер группы и признак `armed`. Повторный выбор того же номера снимает выделение, другой номер выбирается. `armReplace` перед заменой взводит признак: следующая смена regex погашает его, сохраняя номер; обычная смена regex снимает выделение. Смена примера и выход из «Групп» также снимают его. Хук вычисляет диапазон по номеру и токенам; исчезновение группы вызывает обычное снятие выделения. Отдельное событие не нужно, порядок эффектов даёт одинаковый результат.

Преобразование токена в номер и проверка режима перед выбором остаются у вызывающего. Хук получает номер одинаково от клика и иконки, а отдаёт выбранный номер, диапазон и операции выбора, снятия и подготовки замены. Постановка выделения CodeMirror, вставка через редактор и смешение с подсветкой активного токена остаются снаружи. Режим нужен хуку только для сброса при выходе; редьюсер не хранит ни режим, ни знание токенов.

Инварианты проверяются переходами без React и CodeMirror, проводка диапазона — тестами хука, проверки редактора контролируют итоговое поведение. Возможные спорные изменения поведения требуют отдельного решения.

Перенос эффектов в хук без редьюсера отвергнут, поскольку сохраняет хрупкий флаг. Отдельное событие существования группы отвергнуто как дублирование снятия. Полная подсветка внутри хука отвергнута как включение чужого понятия активного токена. Преобразование токена в номер внутри отвергнуто, поскольку создало бы разные входы для клика и иконки.
