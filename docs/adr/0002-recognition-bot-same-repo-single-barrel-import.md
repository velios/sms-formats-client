# Бот распознавания в общем репозитории с единой границей импорта

Telegram-бот должен возвращать форматы, распознающие SMS, через то же ядро, что и редактор. Ядро должно оставаться идентичным распознаванию на устройстве; независимая копия создаёт риск расхождения ([ADR-0001](0001-normalize-text-before-recognition.md)).

Бот — отдельное Bun-приложение в этом репозитории. Он импортирует ядро только через публичную точку `@/domain/format`, без прямых импортов остальных файлов `src/`. Граница держится соглашением: изменение внутреннего пути ядра может затронуть бот. Зависимости фронтенда и бота находятся в общем `package.json`, но деплой раздельный: статический фронтенд и долгоживущий бот разворачиваются отдельными приложениями Dokku.

Выделение пакета в workspace отложено: выгода пока не оправдывает риск рефакторинга работающего фронтенда; единая точка импорта оставляет переход механическим. Отдельный репозиторий с опубликованным пакетом отвергнут из-за риска рассинхронизации версий ядра.
