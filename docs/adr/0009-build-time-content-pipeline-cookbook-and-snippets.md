# Справочник и сниппеты собираются встроенными средствами Bun

Редактору нужны справочник лучших практик regex (cookbook) и каталог вставляемых фрагментов — сниппетов. В браузере API Bun недоступны, новые клиентские библиотеки не вводятся, а каталог должен редактироваться без правки кода. Поэтому контент собирается встроенными средствами закреплённого в проекте Bun до сборки клиентского бандла.

Cookbook хранится в репозитории как вручную обновляемый Markdown-снимок внешнего справочника. `Bun.markdown.html()` преобразует его с поддержкой GFM-таблиц в HTML для полноэкранного окна. Вставка HTML допустима только для этого доверенного, зафиксированного при сборке источника. Рядом может оставаться ссылка на актуальную версию GitHub. Принятый минус снимка — ручная синхронизация; преимущества — воспроизводимость и работа без сети.

Сниппеты хранятся независимо в человекоредактируемом TOML с именованными полями: паттерн, сущность, описание, условия применения, пример, ограничения и признак основного или альтернативного варианта. Литеральные строки сохраняют обратные слэши regex дословно. Нативный импорт Bun превращает источник в типизированный каталог. Каталог обновляется отдельно от cookbook и может расходиться с ним.

Каталог находится во вкладке правой панели рядом с редактором: фильтр по сущностям и карточки со всеми полями. Он остаётся открытым после вставки и скрыт в режиме чтения. Вставка идёт в позицию курсора или заменяет выбранную группу по правилам ADR-0010. Устаревшие паттерны «не копировать» карточками не показываются. Проза каталога русская, структурные метки интерфейса переводятся на русский и английский.

Фрагменты без группы захвата — штатная категория `glue`: соединители, якоря и пропуск лишнего токена без включения в извлекаемое значение. Например, ленивый пропуск после узкой группы устойчивее жёстко заданного лишнего токена. Такие карточки оформляются как остальные, но рассчитаны на вставку в каретку. При замене группы и исчезновении её номера выделение сбрасывается ([ADR-0010](0010-capture-group-selection-for-snippet-replacement.md)).

Только внешняя ссылка на справочник отвергнута, поскольку нужно чтение внутри приложения. Клиентский Markdown-парсер с загрузкой актуального текста отвергнут из-за новой зависимости. Каталог в TypeScript отвергнут как недоступный редактору без навыков кода; извлечение из cookbook — из-за хрупкого разбора прозы. Markdown со строгой схемой отвергнут из-за собственного парсера, YAML — из-за отсутствия нативной поддержки Bun и необходимости библиотеки.
