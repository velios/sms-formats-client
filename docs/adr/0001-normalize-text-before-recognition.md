# Нормализация текста внутри распознавания

Мобильное приложение Zenmoney перед распознаванием заменяет последовательности `\n`/`\r` одним пробелом и обрезает края. Без той же нормализации редактор распознаёт многострочные SMS иначе.

Каноническая нормализация выполняется внутри `testRegex`; пути проверки без координат вызывают ту же функцию напрямую. Примеры, черновики, файлы и введённые SMS сохраняют исходный текст. Координаты совпадения и групп переводятся обратно в исходную строку, чтобы подсветка и потребители API продолжали работать с ней.

Значения групп остаются нормализованными, как извлекаемые на устройстве данные, и могут отличаться от исходного фрагмента между возвращёнными координатами. Это принятый компромисс, требующий преобразования позиций.

Нормализация в местах вызова отвергнута: новый потребитель мог бы её забыть. Показ нормализованного текста вместо оригинала отвергнут: редактируемый пример записывается в формат и потерял бы переносы.
